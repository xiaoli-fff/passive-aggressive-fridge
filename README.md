One dry, petty note a smart fridge leaves its owner: its sensors caught the expired yogurt, and unlike its owner, it finishes what it starts.

## Run it

```sh
node main.ts
```

The program writes the one line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
